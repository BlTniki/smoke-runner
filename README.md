# Smoke Runner

Личный Telegram-бот, который помогает постепенно увеличивать паузы между
эпизодами использования вейпа и видеть измеримый прогресс.

Продуктовые требования согласованы. Код намеренно ещё не выбран и не написан:
следующий этап — архитектурные решения и план реализации.
