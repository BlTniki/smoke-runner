# Smoke Runner

Личный Telegram-бот, который помогает постепенно увеличивать паузы между
эпизодами использования вейпа и видеть измеримый прогресс.

Продуктовые требования и архитектура согласованы. Реализация ведётся пакетами
из плана ниже; текущий этап — каркас Python-проекта.

## Локальная разработка

Требуется Python 3.14 и [uv](https://docs.astral.sh/uv/). Docker на рабочем
ноутбуке не нужен.

```bash
uv sync --locked
SMOKE_RUNNER_DATABASE_PATH=./data/smoke-runner.sqlite3 uv run alembic upgrade head
uv run python -m smoke_runner --help
make check
```

Настройки для будущего запуска бота перечислены в `.env.example`; тесты и
справка CLI не требуют настоящих секретов.
